# 需求文档

## 1. 应用概述

### 1.1 应用名称
终末地寻光笔记（Jev保姆级工具箱）

### 1.2 应用描述
在个人学习笔记系统的基础上，升级为类操作系统体验的个人知识工具箱。系统提供全局常驻唤出入口、单键快捷启动机制、自动折叠导航栏，内置划词自动翻译的中英重点标注工具与笔记系统，并支持自主扩展个性化工具。

## 2. 用户与使用场景

### 2.1 目标用户
网站所有者本人，用于个人知识笔记管理与效率工具集成。

### 2.2 核心使用场景
- 通过全局悬浮按钮或快捷键快速唤出工具箱启动面板或直达对应工具
- 桌面端左侧导航平时自动折叠以拓展正文操作空间，鼠标悬停时快速导航
- 在「中英重点标注」工具中鼠标滑动选中中文词汇，系统自动查询英文并生成对照标注，一键转存为笔记
- 自主添加第三方工具或自定义功能入口，配置专属快捷键
- 进行常规笔记的录入、分类整理、检索与系统管理

## 3. 页面结构与功能说明

### 3.1 页面结构

```
终末地寻光笔记
├── 全局导航与常驻层
│   ├── 左侧导航栏（桌面端自动折叠/移动端抽屉）
│   ├── 悬浮唤出按钮
│   ├── 工具箱启动面板（Jev工具箱）
│   └── 自定义工具管理弹窗
├── 笔记应用模块
│   ├── 首页
│   ├── 笔记列表页
│   ├── 笔记详情页
│   ├── 笔记编辑页（新建/修改）
│   └── 管理员面板（笔记管理、分类管理）
└── 内置工具模块
    └── 中英重点标注工具（划词自动翻译与对照生成）
```

### 3.2 功能说明

#### 3.2.1 全局导航与常驻层

##### 3.2.1.1 左侧导航栏
- 包含导航项：首页、全部笔记、管理面板。
- 桌面端交互：默认处于折叠状态（仅展示图标窄条）；当鼠标悬停于导航区域时自动展开显示完整文本菜单，鼠标移出后自动恢复折叠状态。
- 移动端交互：保留顶部抽屉菜单形式展开与收起，不受自动折叠规则影响。

##### 3.2.1.2 悬浮唤出按钮
- 页面右侧常驻显示唤出入口，点击可展开或收起「工具箱启动面板」。
- 支持键盘快捷键（如 Esc 或特定预设键）快速唤出/关闭面板。

##### 3.2.1.3 工具箱启动面板（Jev工具箱）
- 展示所有内置应用与用户自定义工具卡片，展示工具名称、功能描述、绑定的单键快捷键标签。
- 点击工具卡片直接打开对应功能；非文本输入状态下按下单键快捷键直接调起对应工具。
- 提供「添加自定义工具」操作入口。

##### 3.2.1.4 自定义工具管理
- 支持新增、编辑、删除自定义工具，填写工具名称、链接/描述并绑定单键快捷键（A-Z、0-9等）。
- 自定义工具数据持久化存储至后端。

#### 3.2.2 内置工具：中英重点标注工具
- 文本输入区：支持输入与编辑中文正文。
- 划词自动查询与标注：
  - 用户使用鼠标滑动选中中文文本（或移动端触屏完成选词）后，系统触发防抖并自动发起英文术语查询。
  - 查询期间在选中文本附近提供加载中状态反馈。
  - 查询成功后，自动在正文中将选中文本转换为中英对照格式标注，并同步更新标注词条列表。
  - 查询失败或返回为空时，弹出手动输入英文弹窗作为兜底，支持用户手动输入并确认生成标注。
- 词条管理与对照预览：支持查看已标注词条列表、一键移除特定标注、实时查看对照排版效果。
- 保存为笔记：一键将当前标注内容预填导入新建笔记页面。

#### 3.2.3 笔记应用模块

##### 3.2.3.1 首页
- 展示网站概览与快捷操作入口（新建笔记、进入笔记列表、打开中英标注工具），展示最近更新笔记（最多5条）。

##### 3.2.3.2 笔记列表页
- 展示笔记条目（标题、所属领域、创建时间、更新时间），支持分类筛选、关键词搜索与排序。

##### 3.2.3.3 笔记详情页
- 展示完整笔记内容（含中英标注排版），提供编辑、删除与返回操作。

##### 3.2.3.4 笔记编辑页（新建/修改）
- 编辑笔记标题、选择所属领域、编辑正文（支持接收来自中英标注工具导入的文本），保存至后端。

##### 3.2.3.5 管理员面板
- 笔记管理（查看全部、批量删除、统计）与分类管理（新增、编辑、删除领域分类）。

## 4. 业务规则与核心逻辑

### 4.1 划词自动标注规则
- 触发时机：检测到文本选区改变且选区非空、长度大于等于1个字符时，触发防抖后自动请求翻译服务。
- 重复标注防护：若选中的文本范围已包含已存在的标注格式，或选中区域包含已有对照标签，则不重复发起查询，避免格式嵌套破坏。
- 兜底逻辑：若翻译服务接口报错、超时或未匹配到有效结果，自动呼出手动输入英文弹窗，确保标注流程不中断。

### 4.2 导航折叠响应逻辑
- 桌面端视口下，侧边栏基础宽度为折叠态，悬停激活展开态，不占用主内容区的固定布局宽度，移开后平滑收回。
- 移动端视口下不应用鼠标悬停折叠机制，维持独立的抽屉导航模式。

### 4.3 快捷键触发规则
- 仅在非输入框聚焦状态下响应单键快捷启动。
- 快捷键全局唯一，不允许重复绑定相同按键。

### 4.4 中英标注转笔记逻辑
- 点击「保存为笔记」时，自动提取正文填充至新建笔记流程，选定分类后提交保存。

## 5. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 划词选中文本后翻译接口调用失败或超时 | 结束加载状态，自动弹出手动输入弹窗，允许用户手动录入英文术语 |
| 划词选中内容为空白字符或纯标点 | 不触发翻译请求与标注操作 |
| 选中文本已处于标注格式内 | 忽略本次选词请求，不重复生成嵌套标注 |
| 鼠标快速滑过左侧导航未作停留 | 防抖处理，避免频繁闪烁展开 |
| 自定义工具绑定已被占用的快捷键 | 提示「该快捷键已被占用，请更换其他按键」并阻止保存 |
| 删除仍包含关联笔记的分类 | 提示「该分类下存在笔记，无法删除」并阻止操作 |

## 6. 验收标准

1. 桌面端访问页面时，左侧导航默认呈图标折叠状态，鼠标悬停时展开显示完整文字菜单，鼠标移开后恢复折叠。
2. 在中英标注工具正文中用鼠标滑动选中一段中文词汇，系统展示查询中状态，并在查询成功后自动在正文生成中英对照标注。
3. 在中英标注工具中选词且翻译服务无返回或失败时，界面自动弹出手动录入弹窗，输入英文确认后能正确生成对照标注。
4. 选词生成对照标注后，点击「保存为笔记」可成功将带有标注的内容导入新建笔记页面并完成保存。
5. 在非输入框聚焦状态下按下绑定的单键快捷键，能直接唤出对应工具面板或跳转对应页面。
